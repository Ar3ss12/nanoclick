ABOUT NANOCLICK
NANOCLICK v1.0-beta BETA

High-performance, bloat-free desktop automation engine built with pure Rust.

🦀 Pure Rust Core
~3.5 MB installer, 15 MB RAM. No Electron, no hidden background services, no garbage collection freezes.
🛡️ Smart Guard Engine
UIPI elevation handling for Admin windows and intelligent hotkey lockout while typing in chat.
📐 RDP Vector Compression
Ramer-Douglas-Peucker algorithm compresses recorded mouse paths up to 95% preserving natural curves.
⚡ Sub-Millisecond Input
Configurable 5ms debounce, floating real-time stats HUD and GPU-accelerated click ripples.

🛡️ Windows UIPI — Administrator Rights Required

⚠️
Click attempt blocked by Windows UIPI security system.
The target window is running with elevated privileges (Administrator / UAC), while NanoClick is running in standard mode. Windows prohibits standard processes from sending SendInput to elevated windows.

To click into protected windows (Task Manager, elevated terminals, protected games, etc.), restart NanoClick as Administrator.
